# Cookie Clicker PS Edition

A simple PlayStation-themed cookie clicker game built with plain HTML, CSS, and JavaScript.

## Run it locally

Open `index.html` in a browser, or serve the folder with a simple local web server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Features

- PlayStation-inspired dark console UI
- Cookie clicker gameplay loop
- Upgrade store and auto-clicker progression
- Trophy/achievement system
- Local save using `localStorage`
